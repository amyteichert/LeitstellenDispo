# LeitstellenDispo – Entwicklungsplan

Dieses Dokument fasst die vereinbarten Projektentscheidungen zusammen.

## Kernentscheidungen

- **Name:** LeitstellenDispo
- **Karte:** Echte Weltkarte (MapLibre + OpenStreetMap), skalierbar
- **Organisationen (Start):** Feuerwehr + Rettungsdienst
- **Grundfahrzeuge (früh):** LF 10, LF 20, RTW
- **Später freischaltbar:** KTW, NEF, DLK, GW-Öl, weitere Spezialfahrzeuge
- **Statussystem:** Architektur für Status 1–6 vorbereitet
- **Design:** Hell, rot, Leitstellen-Optik; Themes später
- **Owner-System:** Rollen ab Phase 1 vorbereiten, Admin-Menü ab Phase 9
- **Kosten:** Entwicklung komplett kostenlos lokal
